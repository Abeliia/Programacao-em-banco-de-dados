# Sistema Oficina Mecânica

## Objetivo

Modelar e implementar um banco de dados para gerenciamento de uma oficina mecânica.

## Conceitos aplicados

- CREATE TABLE
- PRIMARY KEY
- FOREIGN KEY
- INSERT
- UPDATE
- SELECT
- JOIN
- GROUP BY

## Estrutura

- Clientes
- Veículos
- Mecânicos
- Ordens de serviço
- Peças

## Desafios

### Desafio 1
Com as tabelas prontas, inserção de dados.

### Desafio 2
Inserção de dados de teste.

### Desafio 3
Consultas utilizando JOIN.

### Desafio 4
Relatórios.

### Desafio 5
Consultas avançadas.
